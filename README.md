# ☕ Heritage Coffee House

A responsive coffee shop website developed using **HTML5, CSS3, Bootstrap 5, and JavaScript**. The project showcases a modern, user-friendly interface with responsive design, ensuring a seamless experience across desktop, tablet, and mobile devices.

## 🌟 Features

* Responsive design for all screen sizes
* Modern and clean user interface
* Home, Products, Franchise, About, Contact, and Enquiry pages
* Bootstrap 5 components for responsive layouts
* Interactive elements using JavaScript
* Easy-to-navigate interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
